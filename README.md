# 🎧 VibeCast Studio

**VibeCast Studio** — это веб-приложение для прослушивания музыки и подкастов с возможностью авторизации, добавления треков в избранное и удобным адаптивным плеером.

## 🚀 Функционал

*   **Авторизация и регистрация:** Вход и создание аккаунта с валидацией данных (Zod) и защитой паролей.
*   **Список треков:** Отображение всех доступных композиций с информацией об альбоме, длительности и дате добавления.
*   **Поиск:** Мгновенная фильтрация треков по названию и исполнителю.
*   **Избранное:** Добавление и удаление треков из списка избранного (синхронизация с сервером).
*   **Аудиоплеер:**
    *   Воспроизведение / пауза.
    *   Перемотка по шкале (клик или перетаскивание).
    *   Перемотка ±10 секунд с клавиатуры (стрелки).
    *   Переключение на следующий/предыдущий трек.
    *   Регулировка громкости и режим Mute.
*   **Пагинация:** Классическая пагинация для десктопа и ленивая подгрузка (Infinite Scroll) для мобильных устройств.
*   **Профиль:** Страница с информацией о пользователе и кнопкой выхода.
*   **Адаптивность:** Полная поддержка мобильных устройств, планшетов и десктопов (брейкпоинты 360px, 550px, 800px, 1100px).

## 🛠️ Технологии

*   **Frontend:**
    *   TypeScript
    *   Vite (сборщик)
    *   RE:DOM (легковесная библиотека для работы с DOM)
    *   Zod (валидация данных)
    *   CSS (БЭМ, Flexbox, Grid, медиазапросы)
*   **Backend (локальный):**
    *   Express.js (Node.js)
    *   JWT (JSON Web Tokens) для авторизации
    *   bcrypt (хеширование паролей)

## 📦 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/sttrannik1977rab/VibeCast-Studio.git
cd VibeCast-Studio
```
### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск бэкенда
Бэкенд находится в папке src/express-backend. Перейдите в неё и запустите сервер:
```bash
cd src/express-backend
npm run start
```
Сервер запустится на http://localhost:8000.

### 4. Запуск фронтенда
Откройте новый терминал в корне проекта (там, где package.json с Vite) и выполните:
```bash
npm run dev
```
Приложение откроется по адресу http://localhost:3000.

### 5. Сборка для продакшена
```bash
npm run build
```

## 🧹 Линтинг
Проект настроен на строгую проверку кода с помощью ESLint (запрет any, проверка неиспользуемых переменных).

## 📝 Примечания
Аудиофайлы: Бэкенд отдает треки в формате base64 (encoded_audio). Для предотвращения ошибок при отсутствии реальных данных используется fallback на тестовый MP3-файл.

Адаптивность: Для мобильных устройств (ширина <= 550px) реализована ленивая подгрузка треков через IntersectionObserver.
